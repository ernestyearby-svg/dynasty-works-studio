## Recommendation and builder changes

Seven screens remain. Stage, assets, selected scope, physical intent, readiness, launch window and preference produce only applicable phases. Prerequisites precede dependent work, existing identity is preserved unless redesign is explicit, absent websites/stores receive creation work instead of optimization, and unready physical-market work appears as future scope. Type-specific suggestions are optional and bounded by expressed intent. Package selection is preliminary and does not force all package services into a roadmap. Download includes the full sequence and reasons.

## Boundaries, pricing, backend and security

DIRECT / COORDINATED / PROFESSIONAL_REQUIRED are reusable classifications with plain-language public descriptions. Regulated work is referred to outside authorized specialists; no named partnerships or client results were invented. All package publicPrice values are null. Internal pricing fields have no values and are absent from client output. Contact information, written budget and referral text remain memory-only. Only non-contact tab-session choices recover; old contact drafts are scrubbed. Payload submission consent stays false. No backend, CRM, Supabase connection, private portal, payments or analytics collection is enabled. Private documentation is outside public output.
