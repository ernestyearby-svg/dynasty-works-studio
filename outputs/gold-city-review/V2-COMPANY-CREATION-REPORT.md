## Four-stage implementation

`data/company-creation.ts` owns public stage descriptions, scope and practice links. Formation/trademark/regulatory work is described as coordination or specialist preparation. LAUNCH/SCALE include distribution and activation preparation without claiming licenses.

Each of the ten existing recommendation phases maps once to a public stage. Foundation → DEFINE. Brand, Product/Infrastructure, Digital → BUILD. Commercialization, Launch, Distribution, Activation → LAUNCH. Automation System and Growth → SCALE. This is a presentation layer, not a replacement for the engine, a maturity score or a requirement that every founder buy all stages. Cross-functional practices can appear in multiple public capability stages.
