# V5.7 Cinematic Environment System — local prototype

Checkpoint: d5791acb0a2967131a91815850edfca986fd0e4e; current V5.7 changes are uncommitted. V5.5B and V5.6 source snapshots remain in experience-integration/outputs/v55b-preserved and v56-preserved.
URL: http://localhost:5186/visual-environment-lab
Scope: lab only. No deployment, promotion, investor change, GitHub main change, or MyMosa work.

## Architecture and refinement
One persistent Three.js scene consumes the existing CreationEnvironmentState. No additional scroll listener or timing controller. Geometry builds via smooth progress interpolation, then returns to identical earlier geometry on reverse scroll. Shared unit box, four primary surface materials, separate emissive light materials. Neutral ambient/key illumination; localized warm aperture source. Mobile camera deliberately crops vertically and omits distant bays/volumes and alternating ribs. DPR capped at 1 mobile, 1.5 desktop. No pointer/device-orientation dependency.

Lightweight loads beneath the renderer; WebGL reveals only after the first submitted frame. Lazy import, initialization failure, render exception and context loss return to the preserved lightweight layer. Constructor failure and simulated context loss were tested. Root homepage does not request the renderer. No loading spinner, forced delay or geometry remount between stages. Rendering is event-driven and stops beyond the sequence or while document is hidden. Reduced motion removes camera interpolation and resolves added structural parts at stage completion. No continuous idle animation.

## Resources
Three.js 0.186.0. No new dependency since V5.6. One shared box geometry for 43 desktop / 30 mobile Company parts; 516 / 360 authored triangles. Four geometry resources reported by renderer including internal processing. Render-pass triangle counts include shadows.
One generated 128x128 RGBA material map (65,536 CPU bytes) and six 1x1 neutral cube faces (24 CPU bytes). Seven GPU textures reported including internal conversion and shadow targets. Downloaded textures: zero. Shadow map: 1024 desktop / 512 mobile at initialization. Shadows only cast from significant near structural masses. Cube environment is neutral, not a captured future scene; floor response is approximate physical specular response, not scene-accurate planar reflection.

## QA
Build / TypeScript / lint PASS. Console clean in normal runs. Expected unsupported-WebGL constructor log occurs only in forced-failure test. All eight foreground SVG/placement/text states match the root at desktop/mobile after renderer readiness. The first old 90ms harness attempt sampled Idea during initialization; rerun explicitly waited for readiness and all states matched. Locked controller and Artifact source unchanged. Overflow passes 320/360/375/390/430/768/1024/1280/1440/1920/2560. Keyboard stage selection passes.

No external authenticated deployment console retest. Mobile timings are browser viewport simulation on desktop hardware; real phone performance remains unverified. Init excludes download and is cache/driver dependent. Frame values measure browser intervals during forward/reverse scrolling, not GPU execution duration. GPU timer query not measured. No video: existing recorder lacks FFmpeg. Forward/reverse state evidence is in v57-qa.json.

## Limitations
Lazy chunk is slightly above the requested V5.6 ceiling; retain as an explicit prototype exception for review, not a claim of meeting the ceiling. Vite's >500KB warning is not suppressed. Surface and shadow quality remains subject to founder approval; this is not a final art-direction approval. No physical global illumination or ray tracing. No automatic low-power classifier is claimed.
