## Source audit
DWS uses cross-document CSS View Transitions, not document.startViewTransition. ExperienceSystem.tsx observes native pageswap/pagereveal, already handles ready rejection with AbortError discrimination, handles finished resolution/rejection and skips spatial transition for reduced motion or hidden document. No updateCallbackDone consumer exists. Web Animation finished cancellation for the continuity clone is also handled. No new suppression added; broader changes to existing handling would be speculative and outside a proven defect.

Primary references:
- https://developer.chrome.com/docs/web-platform/view-transitions/cross-document
- https://www.w3.org/TR/css-view-transitions-1/
These document skipped transitions and ready rejection; successful navigation/update is distinct from animation readiness.
