## Workline and motion

Reusable Workline and WorkNode primitives connect the experience. Draw animates line construction; Resolve changes discipline geometry; Transfer is expressed through the retained core geometry across sequential acts; Reveal uses a structural text mask. Animations complete in 600–900 ms, triggered once on entry or by intentional selection. No perpetual animation, custom cursor, scroll hijacking, or animation dependency.

OS `prefers-reduced-motion`, the existing site motion preference, and a prototype Reduce motion control suppress motion. Static content and diagrams remain complete.

## Mobile and accessibility

- Mobile navigation becomes a fullscreen typographic menu with Escape dismissal, focus return, a keyboard focus loop, and body scroll locking.
- Disciplines become vertical tap states along the Workline. Arrow keys, Home, and End select tabs; only the selected tab is in the tab order.
- Native radio inputs, live selection explanation, visible cobalt focus, logical headings, text equivalents for decorative diagrams, and meaningful links.
- Ten viewport checks: 320, 360, 375, 390, 430, 768, 1024, 1440, 1920, 2560 px. No horizontal overflow or overflowing headline content observed.
- Live Builder checked at the same widths. A business type selection successfully advanced to Starting point.
- Cobalt contrast: 4.79:1 on Paper, 5.27:1 on Pure; 3.64:1 on Ink, where it is used for graphical connections rather than small text. Ink/Pure supply body-text contrast.
- Reduced-motion control verified: zero active CSS animation names after activation. OS preference rules reviewed in code; no separate OS-level emulation was available.
